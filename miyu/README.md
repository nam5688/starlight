# 미유

개인 통합 분석 리포트 — 사주 · MBTI · 기질 · 애착.

현재 단계: 메인 · 검사 · 결과 화면을 **샘플 데이터**로 구현한 미리보기입니다. 로그인 · 저장 · 결제는 아직 연결하지 않았습니다.

```bash
npm install
npm run dev     # http://localhost:3000
```

| 화면 | 주소 |
| --- | --- |
| 메인 | `/` |
| 검사 | `/test` |
| 결과 (샘플) | `/result` |

Vercel에 배포할 때는 프로젝트 설정의 Root Directory를 `miyu`로 지정합니다.

제품 · 디자인 · 보안 규칙과 다음 단계는 레포 루트의 [`CLAUDE.md`](../CLAUDE.md)에 있습니다.
