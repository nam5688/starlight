# 실제 AI 유료 리포트 품질 확인 계획 (후보 2개 · 비용 · 평가 방법)

- 상태: **계획 (승인 전 — 유료 호출을 하지 않았다).** 승인 전에는 실제 AI 제공사에 연결하지 않고, 어떤 키도 받지 않는다.
- 목적: "돈을 받을 만큼 무료와 다른가"를 실제 AI 문장으로 판단한다. 잠금 화면이 좋아졌다는 것과 유료 상품이 좋아졌다는 것은 별개이므로, 이 확인이 출시 전 가장 중요한 일이다.
- 함께 볼 문서: [`report-quality-samples.md`](./report-quality-samples.md)(무료와 유료 샘플 나란히 · 목표 수준) · [`service-v2-proposal.md`](./service-v2-proposal.md) 7장(전체 후보 가격표)

## 1. 후보 2개

| | 후보 A | 후보 B |
| --- | --- | --- |
| 회사 · 모델 | Anthropic **Claude Sonnet 5.5** | OpenAI **GPT-6.1 Sol** |
| 가격 (입력 / 출력, 100만 토큰당) | $2 / $10 | $2 / $10 |
| 등급 | 가운데 등급, 정식 출시 | 가운데 등급, 정식 출시 |
| 건당 예상 비용 | 약 110~240원 | 약 110~240원 |

**왜 이 둘인가:** 같은 가격대(건당 100~250원)의 정식 출시된 가운데 등급이고, 구조화된 JSON 출력과 한국어 긴 글을 쓴다. 미유의 리포트 생성은 "근거 목록 안에서만 쓰기 → 형식 검사 → 통과한 것만 저장"이라 모델이 바뀌어도 코드는 그대로다 (`lib/report/ai/`의 `TextModel` 약속).

**후보에서 뺀 것과 이유**
- Google Gemini 3.1 Pro: 아직 미리보기 단계라 모델 · 가격이 바뀔 수 있다. 정식 출시 후 다시 본다.
- 최상위 등급(Claude Opus 5.5 건당 약 280원 · GPT-6 Astra 약 690원): 가운데 등급이 기준에 못 미칠 때만 2단계로 확인한다. 9,900원 상품에서 건당 280원도 감당할 수 있으므로(5장) 비용이 아니라 "필요한지"로 판단한다.
- 가장 싼 등급(Haiku · Luna 계열, 건당 약 7원): 긴 개인 해석에는 맞지 않을 가능성이 커서 이번 비교에서 제외. 무료 문장 보조나 오늘 운세 같은 짧은 글에서 따로 검토한다.

**알려 둘 것(편향):** 저는 Anthropic이 만든 모델이라 후보 A를 유리하게 볼 수 있다. 그래서 ① 두 모델에 **같은 지시문 · 같은 입력**을 그대로 쓰고(어느 한쪽에 맞춰 고치지 않음) ② **어느 글이 어느 모델 것인지 가린 채** 운영자가 평가하며 ③ 채점표를 **결과를 보기 전에** 고정한다. OpenAI 가격은 OpenAI 공식 가격표를 직접 열지 못했고, 가격 정리 사이트 두 곳(2026-10 초 기준)에서 확인한 값이다 — 가입 화면에서 한 번 더 확인해 달라.

## 2. 월 구독료와 API 비용은 다르다

| | 월 구독 (ChatGPT Plus · Claude Pro 등) | API (미유 서버가 쓰는 것) |
| --- | --- | --- |
| 무엇인가 | 사람이 앱 · 웹에서 대화하는 **이용권** | 프로그램이 호출하는 **종량제** (쓴 토큰만큼) |
| 미유에 쓸 수 있나 | **쓸 수 없다** (구독이 있어도 API 호출은 별도) | 쓴다 |
| 비용 | 월 정액 | 리포트 한 건 생성에 약 110~240원 (아래 3장) |
| 가입 | 이미 있어도 무관 | **별도 API 계정**, 결제수단 등록 또는 선불 충전, 키 발급 |

- 서비스 운영 시 월 AI 비용 = 팔린 리포트 수 × 건당 비용. 예: 월 100건 → 약 1.1만~2.4만 원, 월 1,000건 → 약 11만~24만 원 (재시도 포함 시 더).
- 선불 충전에는 회사별 **최소 금액**이 있을 수 있다 (몇 달러 단위). 실제 쓰는 금액은 아래 한도 안이지만 **충전 금액은 그보다 클 수 있다** — 가입 화면에서 확인하고, 필요 이상으로 충전하지 않는다.
- 부가세 등으로 표시 가격보다 약 10% 더 청구될 수 있다 (회사 · 결제 조건별로 다름).
- 두 회사 콘솔에서 **월 사용 한도(spend limit)** 를 5천~1만 원 수준으로 걸어 두는 것을 권한다 (미유 쪽 하드 스톱과 별도의 이중 안전장치).

## 3. 예상 비용 (계산 근거)

- 입력: 시스템 지시문 약 2,700자 + 근거 목록 약 5,700~7,400자 (가상 인물 3명으로 실제 측정). 한국어 글자 수 ≈ 토큰 수로 보수적으로 잡아 **약 6,500~10,000토큰.**
- 출력: 목표 수준 예시의 JSON이 약 5,900자(≈ 4,000~6,000토큰). 여기에 모델이 생각하는 데 쓰는 토큰(출력으로 과금됨)이 더해져 **약 6,000~14,000토큰.**
- 환율 1달러 = 1,500원 가정 (10월 환율은 확인 필요).

| | 입력 | 출력 | 건당 비용 |
| --- | --- | --- | --- |
| 적게 쓸 때 | 6,500 | 6,000 | $0.073 ≈ **110원** |
| 많이 쓸 때 | 10,000 | 14,000 | $0.160 ≈ **240원** |
| 형식 검사 실패로 한 번 고쳐 쓰면 (최대 1회, 제품 설계) | 위의 약 2배 | | 최대 약 **480원** |

**이번 비교의 전체 비용**
- 가상 인물 10명 × 모델 2개 = **20건.** 보통 약 3,000원 · 재시도 포함 약 3,600원 · 최악(모두 많이 쓰고 모두 한 번씩 고쳐 쓰기) 약 9,600원.
- **승인 요청: 두 회사 합쳐 총 1만 원 한도 (회사당 5,000원).** 비교 실행기는 호출 전에 예상 비용을 보여 주고, 한도에 닿으면 즉시 멈춘다.

## 4. 같은 입력으로 비교하는 방법

1. **입력:** 가상 인물 10명 (실제 고객 정보 아님). 일간 10종을 한 명씩 포함하도록 만세력 엔진 계산으로 고르고, 성별 있음/없음 · 태어난 시각 있음/모름 · "나를 더 반영하기" 있음(4명)/없음(6명) · 응답 패턴 여러 가지가 섞이게 한다. 이름 · 생년월일 원문은 AI에 보내지 않는 제품 방식 그대로 쓴다.
2. **생성:** 후보 A · B에 같은 지시문(`PROMPT_VERSION`)과 같은 근거 목록을 보낸다. 제품의 형식 검사 · 재시도 규칙 그대로 (실패 시 문제 목록을 주고 1회 다시 쓰기).
3. **자동 측정:** 첫 시도 형식 통과율 · 재시도 후 통과율 · 금지 표현 위반 수 · 근거 ID 오류 수 · 반복 문장 · 글자 수 · 응답 시간 · 입력/출력 토큰 · 건당 비용.
4. **블라인드 평가 (운영자):** 20개 글을 A/B 이름 없이 섞어서, 아래 채점표로 1~5점. 비교 기준으로 사람이 쓴 목표 수준 예시도 같은 채점표로 본다.

| 채점 항목 (5점) | 보는 것 |
| --- | --- |
| 구체성 | 이름을 가려도 이 사람의 이야기로 읽히는가 (같은 말을 아무에게나 해도 되는 문장이 아닌가) |
| 조건 · 상황 | "~할 때 / ~하면 / 다만 ~는" 같은 조건 · 예외가 있는가 |
| 근거 일치 | 문단이 단 근거와 내용이 맞는가 (자동 검사 + 사람 확인) |
| 새로 알게 된 것 | 무료 미리보기에서 얻지 못한 것이 있는가 |
| 한국어 자연스러움 | 번역투 · 반복 · 어색한 문장 |
| 구매 판단 | 읽고 나서 9,900원을 낼 만했는가 / 더 알고 싶은가 |

**합격 기준 (결과를 보기 전에 정해 둠)**
- 지어낸 사건 · 날짜 · 직업 · 나이: **0건** (하나라도 있으면 그 모델은 지시문을 고쳐 다시 확인)
- 첫 시도 형식 통과율 80% 이상, 재시도 후 100%
- 평가 "새로 알게 된 것"과 "구매 판단" 평균 4.0 이상
- 건당 비용 400원 이하
- 둘 다 기준에 못 미치면: 지시문 개선 → 재확인(추가 비용은 새로 요청) → 그래도 안 되면 판매를 미룬다. 최상위 등급 확인은 **별도로 한 번 더 승인을 요청한다.**

**이 비교로 알 수 없는 것:** 사주 해석 자체의 정확성(해석 규칙은 전문가 검토 전 초안), 실제 고객의 만족도, 새 자체 문항(적용 전)으로 만든 근거에서의 품질. 이번 입력은 현재 개발용 문항의 5개 관점이다.

## 5. 이 비용이 상품에 주는 의미

| 항목 (개인 종합 리포트 1건) | 금액 |
| --- | --- |
| 판매가 | 9,900원 (부가세 포함) |
| 부가세 제외 | 약 9,000원 |
| 결제 수수료 (약 3.5% 가정, 계약에 따라 다름) | 약 350원 |
| AI 비용 (이 비교의 가운데 등급 기준) | 약 110~240원 (재시도 포함 최대 480원) |
| 남는 것 | 약 8,200~8,500원 |

AI 비용은 병목이 아니다. **품질이 병목**이다. 그래서 비용 때문에 약한 모델을 고르기보다, 기준을 통과하는 가장 단순한 모델을 고른다.

## 6. 승인 요청 (한 번만)

> **가운데 등급 두 모델(Claude Sonnet 5.5 · GPT-6.1 Sol)로, 가상 인물 10명 × 2 = 20건을 생성하는 비교에 총 1만 원(회사당 5,000원) 한도의 유료 API 호출을 해도 되는가.**
> 실제 고객 정보는 쓰지 않는다. 키는 대화창에 붙여넣지 않는다.

승인하면 다음 순서로 진행한다 (운영자가 하는 일은 1번뿐이다):
1. **운영자:** 두 회사 API 계정 만들기 → 소액 충전 → 콘솔에서 월 사용 한도 5천 원 걸기 → 키 발급 → `.env.local`에만 입력 (내가 단계별로 안내). 키는 채팅에 보내지 않는다.
2. 내가 두 회사 연결 코드(`AI_PROVIDER` 선택지 추가)와 비교 실행기를 만들고, 호출 **전에** 예상 비용을 한 번 더 보여 준다 (연결 단계에서도 유료 호출은 하지 않는다).
3. 운영자 PC에서 실행기를 돌린다 (또는 키를 클라우드 환경 비밀값으로 넣는 방법 — 어느 쪽이든 키는 나에게 보이지 않는다). 결과는 A/B 이름을 가린 파일로 나온다.
4. 블라인드 평가 → 결과 보고 → 선택 또는 지시문 개선.
