운영자 요청(2026-10-20): 지금 화면의 22문항(동의 척도)과 다른 "생활상황 + 행동 선택형 28문항"의 **원래 전체 선택지 · 채점 매핑 · 버전 흔적**을 찾아 복원하고, 원본이 없으면 발견한 범위와 누락을 그대로 보고한다. 임의로 만든 것을 원본 복원이라 부르지 않는다.

## 4. 보존 시험이 지키는 것

`lib/assessment/drafts/situational-v2-provenance.test.ts`(비용 0):
- 28장면 · 선택지 112개의 문장이 위 3절의 운영자 글(장면 문장 + 고른 선택지)과 어긋나지 않는다. 선택지 하나라도 바뀌면 시험이 깨진다.
- 운영자가 고른 28개는 각 장면 선택지 4개 중 정확히 하나와 같다.
- 선택지 데이터에 점수 · 가중치 · 유형 · 방향 필드가 없다(채점은 원본에 없었고 만들지 않았다).
- 이 초안 · 3절의 고른 답이 화면 · 서버 · 저장 · 리포트 · 검사 모듈 · 스크립트 어디에서도 불러와지지 않는다.

## 5. 아직 정해지지 않았고 운영자 결정이 필요한 것

1. 28문항을 새 질문 버전으로 연결할지(운영자는 2026-10-17에 "B로 교체"를 말했지만, 채점 원본이 없어 **읽는 규칙을 미유 쪽에서 새로 정해야 하는 상태**라 아직 구현하지 않았다 — 작업 Q28-1은 대기).
2. 연결한다면 `assessment-situational-v2-review.md` 4절의 읽기 구조 제안(점수 가산 없음 · 여러 장면의 일관성 · 상황별 차이 · 응답 불확실성)을 승인할지. 이는 **창작이므로 원본 복원이 아니라 새 설계**이고, 5~10명 시험 전에는 검증되지 않은 가설이다.
3. 기존 회원의 저장된 22문항 응답은 이전 질문 버전으로 계속 읽는다(대응표를 만들지 않는다).

## 6. 하지 못한 것

- 운영자의 다른 외부 대화창(이 개발 채팅 밖)에 있었을 수 있는 원본 · 채점표는 이 세션이 볼 수 없다 — 있다면 운영자가 붙여 주셔야 한다. 이 채팅 기록 안에서는 채점표가 오간 흔적이 없다.
- 문장의 독립성 · 기존 검사와의 닮음(저작권)은 확인하지 못했다. 초안 파일 머리글대로 외부 AI의 추천으로 전달된 문항이며 미유가 직접 만들었다는 보증이 없다.
- 실제 사람 시험 · 신뢰도 · 타당도는 없다.
