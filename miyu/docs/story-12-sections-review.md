## 1. 지금 story-v1 ↔ 12개 장 매핑

지금 story-v1(`story-v1-prompt-0.3`)의 칸: **headline · cards(강점 · 부담 · 시기 키워드) · 영역 셋(핵심 · 가까운 관계 · 일과 재물) · 시기 · (고민) · 행동 3개**.

| 지금 story-v1 칸 | 새 12개 장 | 관계 |
| --- | --- | --- |
| headline · 핵심 영역 첫 문단 | **01 나의 핵심 성향** | 1 → 1 (유형명은 코드, 지금 화면 꺼짐) |
| 핵심 영역의 사주 근거 문단들(일간 · 오행 · 월령 · 통근 · 강약) | **02 나의 사주 구조** | 핵심 영역 **1칸이 5개 장**(01 · 02 · 03 · 04 · 05)으로 쪼개진다 |
| 핵심 영역의 응답 문단들(4축 · 기질 · MBTI) | **03 타고난 기질과 성격** | |
| (없음 — 22문항에는 맥락을 가를 근거가 없다) | **04 겉으로 보이는 나, 실제의 나** | **새 칸** |
| cards(강점 · 부담) + 핵심 영역의 "강점 → 부담" 흐름 | **05 나의 강점과 약점** | 지금은 카드와 핵심 영역 두 곳에 있다 |
| 가까운 관계 영역 앞부분(표현 · 거리 · 마음 주는 방식) | **06 연애에서의 나** | 1칸이 둘(06 · 07 · 08)로 쪼개진다 |
| 가까운 관계 영역 뒷부분(서운함 · 부딪힘 · 풀어 가는 방식) | **07 애착과 갈등·회복** | |
| (가까운 관계 영역에 섞여 있던 친구 · 동료 이야기 — 근거가 없어 거의 없다) | **08 인간관계와 귀인** | **새 칸**(귀인은 계산 없음) |
| 일과 재물 영역의 일 부분 | **09 일·적성·진로** | 1칸이 둘로 쪼개진다 |
| 일과 재물 영역의 돈 부분 | **10 재물과 돈의 흐름** | |
| 시기 영역(대운 · 세운 · 시나리오) | **11 시기와 변화의 흐름** | 1 → 1, **규칙 그대로**(시기 이야기는 이 장에만) |
| 행동 3개 + 고민 상담(focus) | **12 나를 위한 종합 조언** | 행동은 12에, 고민은 12 안에서 이어 쓰거나 별도 블록으로 둔다(운영자 결정) |

→ 12개 장은 지금 구조의 **4개 영역을 세분한 것 + 새 칸 둘(04 · 08)**이다. 쪼개진 만큼 장마다 쓸 응답 · 사주 근거가 줄어든다.
