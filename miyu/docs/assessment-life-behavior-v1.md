## 1. 왜 새로 설계했나

운영자 요청(2026-10-15): 자체 검사를 만드는 것 자체가 문제가 아니라, **독립적으로 개발했는지 · 기존 검사를 가져왔는지**가 핵심이다. 이름을 바꾸거나 문장만 바꾼다고 독립이 되지 않는다. 점검 결과(`assessment-source-audit.md`) 지금 화면의 22문항은 문장은 직접 썼지만 **방향을 나눈 틀(4 + 4 + 2)이 기존 이론의 틀과 닮았다.** 그래서 이론의 틀이 아니라 **미유가 알아보려는 일상 행동**(계획이 바뀔 때의 대응 · 갈등에서 의견을 말하는 방식 · 시작과 마무리 습관 등)에서 영역을 새로 정했다.

## 4. 문항 36개 (영역마다 서로 다른 장면 3문항)

문항을 읽기 전 안내: "지난 한두 달 동안, 실제로 어땠나요?"  ·  선택지: 거의 없었어요 / 가끔 있었어요 / 자주 있었어요 / 거의 매번 그랬어요 / 그런 일이 없었어요(점수 제외)

### L01 계획이 바뀔 때

일정 · 약속 · 하루 계획이 갑자기 달라졌을 때 첫 반응. (A: 곧바로 다시 짜서 이어 간다 · B: 마음을 정리할 시간이 있어야 다음으로 간다)

- **L01-1** (일) 회의나 마감 일정이 갑자기 바뀌었을 때, 곧바로 내 일정을 다시 짰어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 곧바로 다시 짜서 이어 간다
  - "자주 · 거의 매번"일수록 '곧바로 다시 짜서 이어 간다' 쪽, "거의 없었어요"일수록 '마음을 정리할 시간이 있어야 다음으로 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 일정이 바뀐 직후의 첫 행동을 본다 — 곧바로 다시 짠 경험이 잦으면 '바로 맞춤'
- **L01-2** (약속) 만나기로 한 약속이 바뀌면, 마음을 정리할 시간이 필요해서 바로 답하지 못했어요.
  - "자주 · 거의 매번"이 가리키는 쪽: B — 마음을 정리할 시간이 있어야 다음으로 간다
  - "자주 · 거의 매번"일수록 '마음을 정리할 시간이 있어야 다음으로 간다' 쪽, "거의 없었어요"일수록 '곧바로 다시 짜서 이어 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 약속이 바뀐 직후의 마음 — 정리할 시간이 필요했다는 경험이 잦으면 '시간이 필요함' (일정을 짜는 속도가 아니라 마음의 속도)
- **L01-3** (하루) 하루 계획이 틀어져도, 그 자리에서 다른 일을 정해서 이어 갔어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 곧바로 다시 짜서 이어 간다
  - "자주 · 거의 매번"일수록 '곧바로 다시 짜서 이어 간다' 쪽, "거의 없었어요"일수록 '마음을 정리할 시간이 있어야 다음으로 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 혼자 보내는 하루에서의 대응 — 일 · 약속과 다른 장면에서도 같은지 본다

### L02 시작하는 방식

새 일 · 큰 집안일 · 새로 배우는 일의 첫 행동. (A: 순서와 자료를 정리한 뒤 시작한다 · B: 일단 손부터 대면서 맞춰 간다)

- **L02-1** (일) 새로 맡은 일은 순서를 정리한 뒤에야 첫 작업을 시작했어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 순서와 자료를 정리한 뒤 시작한다
  - "자주 · 거의 매번"일수록 '순서와 자료를 정리한 뒤 시작한다' 쪽, "거의 없었어요"일수록 '일단 손부터 대면서 맞춰 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 새 일의 첫 행동 — 정리가 먼저였는지
- **L02-2** (집) 큰 청소나 집 정리를 계획 없이 눈에 보이는 곳부터 시작했어요.
  - "자주 · 거의 매번"이 가리키는 쪽: B — 일단 손부터 대면서 맞춰 간다
  - "자주 · 거의 매번"일수록 '일단 손부터 대면서 맞춰 간다' 쪽, "거의 없었어요"일수록 '순서와 자료를 정리한 뒤 시작한다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 집안일의 첫 행동 — 계획 없이 손부터 댄 경험 (이 문항은 '자주'가 B 방향이다)
- **L02-3** (배움) 새로운 것을 배울 때 설명서나 후기를 충분히 본 다음에 시작했어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 순서와 자료를 정리한 뒤 시작한다
  - "자주 · 거의 매번"일수록 '순서와 자료를 정리한 뒤 시작한다' 쪽, "거의 없었어요"일수록 '일단 손부터 대면서 맞춰 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 배우는 일의 첫 행동 — 자료 확인이 먼저였는지

### L03 마무리하는 방식

하던 일이 지루해지거나 다른 관심이 생겼을 때 이어 가는지 옮겨 가는지. (A: 시작한 것은 끝낸 뒤에 다음으로 간다 · B: 흥미나 상황이 바뀌면 다른 쪽으로 옮겨 간다)

- **L03-1** (일) 하던 일이 지루해져도 끝낼 때까지 이어 갔어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 시작한 것은 끝낸 뒤에 다음으로 간다
  - "자주 · 거의 매번"일수록 '시작한 것은 끝낸 뒤에 다음으로 간다' 쪽, "거의 없었어요"일수록 '흥미나 상황이 바뀌면 다른 쪽으로 옮겨 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 지루해진 일의 이어 가기 — 끝까지 이어 간 경험
- **L03-2** (취미) 시작한 취미나 공부를 다른 관심이 생겨서 중간에 멈춘 적이 있어요.
  - "자주 · 거의 매번"이 가리키는 쪽: B — 흥미나 상황이 바뀌면 다른 쪽으로 옮겨 간다
  - "자주 · 거의 매번"일수록 '흥미나 상황이 바뀌면 다른 쪽으로 옮겨 간다' 쪽, "거의 없었어요"일수록 '시작한 것은 끝낸 뒤에 다음으로 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 관심이 옮겨 간 경험 — 멈춘 것을 나쁘게 보지 않고 '옮겨 감'으로만 기록
- **L03-3** (마무리) 거의 끝난 일의 마지막 정리(저장 · 제출 · 정돈)까지 직접 마쳤어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 시작한 것은 끝낸 뒤에 다음으로 간다
  - "자주 · 거의 매번"일수록 '시작한 것은 끝낸 뒤에 다음으로 간다' 쪽, "거의 없었어요"일수록 '흥미나 상황이 바뀌면 다른 쪽으로 옮겨 간다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 끝나기 직전의 마지막 정리 — 마무리 습관을 구체적 행동으로 본다

### L04 결정하는 방식

물건 · 메뉴 · 중요한 선택을 정할 때 비교하는 정도와 걸리는 시간. (A: 여러 선택지를 비교하고 시간을 들여 정한다 · B: 빠르게 정하고 넘어간다)

- **L04-1** (물건) 물건을 사기 전에 여러 곳의 가격과 후기를 비교했어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 여러 선택지를 비교하고 시간을 들여 정한다

- **L12-1** (연락) 답이 늦어지면 상대에게 한 번 더 연락해서 확인했어요.

  - "자주 · 거의 매번"일수록 '한 번 더 확인해서 안심한다' 쪽, "거의 없었어요"일수록 '확인하지 않고 기다리며 일상을 보낸다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 답이 늦을 때의 행동 — 다시 연락한 경험
- **L12-2** (결과 기다림) 결과를 기다리는 동안은 따로 확인하지 않고 일상을 보냈어요.
  - "자주 · 거의 매번"이 가리키는 쪽: B — 확인하지 않고 기다리며 일상을 보낸다
  - "자주 · 거의 매번"일수록 '확인하지 않고 기다리며 일상을 보낸다' 쪽, "거의 없었어요"일수록 '한 번 더 확인해서 안심한다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 결과를 기다리는 동안의 행동 — '자주'가 B 방향
- **L12-3** (상대의 마음) 상대가 나를 어떻게 생각하는지 말로 확인하고 싶어서 물어본 적이 있어요.
  - "자주 · 거의 매번"이 가리키는 쪽: A — 한 번 더 확인해서 안심한다
  - "자주 · 거의 매번"일수록 '한 번 더 확인해서 안심한다' 쪽, "거의 없었어요"일수록 '확인하지 않고 기다리며 일상을 보낸다' 쪽으로 읽어요.
  - 이 장면을 고른 이유: 관계에서 말로 확인한 경험 — 상대의 마음을 단정하지 않고 내가 한 행동만 본다

## 5. 읽는 규칙

- 문항 하나의 응답은 영역의 A 방식 쪽 위치(0~100)로 옮긴다: 선택지 1~4를 0 · 33 · 67 · 100으로 놓고, "자주"가 B 방향인 문항은 뒤집는다. "그런 일이 없었어요"는 점수에서 뺀다.
- 영역은 **3문항 모두 답했을 때만** 읽는다(하나라도 해당 없음이면 "답한 문항이 모자라 판단을 보류해요"). 평균 위치가 가운데(50)에서 **20 이상** 벗어나면 뚜렷한 방향, 아니면 "현재 응답만으로는 뚜렷하지 않아요". "약간 ~한 편" · "고르게"로 나누지 않는다.
- 영역을 합친 점수 · 유형 이름 · 사주 점수와의 합산 · 공식 검사 점수로의 환산은 하지 않는다. 결과는 영역을 점수표처럼 늘어놓지 않고 고민과 이어지는 2~3개 영역을 상황 → 반응 → 강점과 어려움 → 작은 행동 순서로 쓴다.
- 영역마다 방향이 섞여 있어(2 : 1) 모든 문항에 같은 답을 골라도 뚜렷한 방향이 되지 않는다(테스트가 확인).

채점 예시(코드로 계산, 실제 응답이 아님):
- L01 계획이 바뀔 때: A 방식 쪽 문항에 "거의 매번", B 방식 쪽 문항에 "거의 없었어요" → 뚜렷한 방향: 곧바로 다시 짜서 이어 간다 (A 방식 쪽 위치 100)
- L01: 세 문항 모두 "자주 있었어요" → 현재 응답만으로는 뚜렷하지 않아요 (A 방식 쪽 위치 56)
- L01: 한 문항이 "그런 일이 없었어요" → 답한 문항이 모자라 판단을 보류해요 (답한 문항 2개)

## 6. 앞선 초안과 같은 일상 주제 (숨기지 않는다)

일상의 행동 주제는 앞선 초안 · 연구가 오래 다뤄 온 것과 겹칠 수밖에 없다. 겹치지 않는다고 주장하지 않는다.

| 이 설계의 영역 | 앞선 초안과 겹치는 주제 |
| --- | --- |
| L01 계획이 바뀔 때 | 화면의 계획 · 일정 문항(m7 · m8)과 일부 같은 주제 |
| L02 시작하는 방식 | 화면의 계획 · 대비 문항(t3 · t4 · m7 · m8)과 닿는 주제 |
| L03 마무리하는 방식 | 화면의 이어 가기 문항(t7 · t8) · 심화 초안의 어려워도 이어 감과 같은 주제 |
| L04 결정하는 방식 | 화면 문항에는 직접 대응이 없다 (m5 · m6은 결정의 기준이고 이것은 비교하는 정도 · 걸리는 시간) |
| L05 새로운 시도 | 화면의 새로움 문항(t1 · t2)과 같은 주제 |
| L06 감정이 올라올 때 | 30문항 초안의 행동을 늦춰 고름 · 심화 초안의 행동을 조절함(D5-3)과 같은 주제 |
| L07 마음을 표현할 때 | 화면의 속마음 문항(r4) · 심화 초안의 마음을 드러내는 편안함(D3-3) · 애정 표현과 같은 주제 |
| L08 갈등에서 의견을 말할 때 | 심화 초안의 갈등에서 의견을 말함(D6-4)과 같은 주제 |
| L09 부탁을 받았을 때 | 심화 초안의 거절 · 경계 세우기(D6-3)와 같은 주제 |
| L10 다툰 뒤 | 심화 초안의 갈등 뒤 회복(D7-4)과 같은 주제 |
| L11 혼자 · 함께 쉬는 방식 | 화면의 에너지 문항(m1 · m2) · 혼자 필요한 시간(r5)과 같은 주제 |
| L12 답이 없을 때 | 화면의 연락 문항(r1 · r2) · 확인받고 싶은 마음과 같은 주제 |

미유가 말할 수 있는 것은 **문항 문장 · 응답 형식 · 채점표를 가져오지 않았고 새로 썼다**는 것까지다. 주제가 겹치는 것이 문제가 되는지, 닮은 문장이 있는지는 판단하지 않았다.

## 7. 확인하지 못한 것 · 다음 단계

- **공식 검사의 문항 원문과 대조하지 못했다.** 원문 · 이용 허락 문서가 없다. 닮은 문장이 없다고 보증하지 않는다 → **검사 저작권을 다루는 전문가가 구체적인 설계안(이 문서 + 문항)을 보고 판단**해야 한다(운영자가 받는다).
- 시범 인터뷰(`assessment-pilot-protocol.md`와 같은 방식: 풀고 "왜 이 답을 골랐는지" 말하기)로 문항이 의도한 뜻으로 읽히는지, "지난 한두 달"을 떠올리기 쉬운지, "그런 일이 없었어요"가 너무 자주 나오지 않는지 본다.
- 지난 한두 달의 기억에 의존하는 방식이라 기억의 쏠림(최근 일 · 인상 깊은 일)이 있을 수 있다.
- 영역당 문항이 3개뿐이라 하나만 해당 없음이어도 읽지 못한다. 시범 응답을 본 뒤 문항을 더하거나 영역을 줄인다.
- 신뢰도 · 타당도 · 정확도는 확인하지 못했다. 이 문서는 장면을 고른 이유와 채점 방향의 기록일 뿐이다.
- 지금 화면의 22문항은 이 설계로 바꾸기 전까지 **개발용 예시**이며 정식 검사로 쓰지 않는다. 바꾸기 전에 공개 페이지(`/assessment-basis`)의 문구를 함께 고친다.
