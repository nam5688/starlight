# 사주 궁합 풀이(compat-v1) 대리 작성기 시험 글 (2026-10-16)

**실제 서비스에 연결된 AI의 글이 아닙니다.** 지시문과 근거 목록(가상 인물 세 쌍 C1 · C2 · C3의 `compatOf` 결과)을 AI 하위 작업자(대리 작성기)에게 파일로 주고 JSON 하나를 쓰게 한 첫 글입니다. 새 유료 호출 0회 · 0원.

| 폴더 | 내용 |
| --- | --- |
| `prompt-0.1/` | 지시문 `compat-v1-prompt-0.1`(원문 `docs/samples/prompts/compat-v1-prompt-0.1.txt`)로 쓴 C1 · C3 첫 글. C1은 제품 검사 통과, C3는 불통과 1건(일간을 "곧 ~"으로 풀이한 설명 방식) — 이유를 주어 고쳐 쓰는 한 번은 하지 않았다 |
| `prompt-0.3/` | **(2026-10-17)** 지시문 `compat-v1-prompt-0.3`(영역 5 + 시기 · 행동 세 묶음 + 건넬 말)으로 독립된 작성기 세 개가 쓴 C1 · C2 · C3. 시기 근거(`compat.timing.*`)가 포함된 요청이다. C1 · C3 통과, C2는 검사의 연도 허용 범위를 고친 뒤 통과(`docs/compat-engine.md` 5-2-1). 개발용 화면 `/dev/compat`은 이 폴더를 읽는다 |
| `prompt-0.2/` | 지시문 `compat-v1-prompt-0.2`로 쓴 C1 · C2 · C3 첫 글. **세 편 모두 제품 검사를 한 번에 통과했다.** 개발용 화면 `/dev/compat`이 이 글을 읽는다(읽을 때마다 제품 검사를 다시 거친다) |

0.2는 0.1 결과를 본 뒤에 고친 사후 수정이라 C1 · C3에 대한 0.1 대비 개선을 지시문 효과라고 말할 수 없습니다(C2만 처음 보는 쌍). 측정 · 읽고 본 것 · 남은 문제 · 말할 수 없는 것은 `docs/compat-engine.md` 5장.
