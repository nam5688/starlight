# 영역별 이야기(story-v1) 대리 작성기 시험 글 (2026-10-16)

**실제 서비스에 연결된 AI의 글이 아닙니다.** 지시문 `story-v1-prompt-0.1`과 근거 목록 파일(가상 인물 P01 · 서윤)을 AI 하위 작업자(대리 작성기)에게 주고 받은 초안을 제품 검사에 넣은 기록이며, 새 유료 호출은 없었습니다(0원). 사람이 문장을 고치지 않았습니다. 좋은 글이라는 증거도, 실제 모델이 같은 구조로 형식 검사를 통과한다는 증거도 아닙니다(지난번 실제 모델은 대리 작성기와 다른 순서로 써서 검사 오탐을 냈습니다).

| 파일 | 내용 |
| --- | --- |
| `P01-round1.json` | P01 1차 — 형식 검사 불통과(연도를 "2026년"으로 적음, 검사가 그때는 숫자 네 자리만 받음). 같은 구절 되풀이 3 |
| `P01-round2.json` · `.md` | P01 2차 — 형식 · 내용 검사 통과, 글 칸 37, 12자 이상 되풀이 0. `.md`는 고객이 읽는 순서로 풀어 쓴 글 전체 |
| `seoyun-round1.json` | 서윤 1차 — 형식 불통과(같은 연도 표기) |
| `seoyun-round2-before-repair.json` | 서윤 2차 처음 글 — 설명 없는 용어("편인") 1건으로 불통과 |
| `seoyun-round2-repaired.json` · `.md` | 같은 오류 한 줄을 알려 주고 그 문장만 고쳐 쓰게 한 글(제품의 고쳐 쓰기 한 번과 같은 절차) — 통과. `lib/samples/sample-story-draft.ts`의 출처 |

검사가 글을 본 뒤에 고쳐진 곳(연도 표기 · 맺음 틀 예산 · "천간합" 오탐)은 사후 수정입니다. 측정과 읽고 알게 된 것은 `docs/story-structure-v1.md` 9장에 있습니다.
