# 질문 3개 묶음 — 남은 질문 처리 정책안 (제안 · 약관 미반영)

- 작성: 2026-10-15 · **제안 문서다.** 약관 · 화면 · 코드에는 아직 반영하지 않았다. 운영자가 아래 6장의 결정 항목에 답하면 그대로 구현하고 약관을 고친다.
- 가격은 건드리지 않는다: **질문 3개 묶음 2,500원(부가세 포함), 낱개 없음**(운영자 확정). 이 문서는 "묶음에서 쓰고 남은 질문 1~2개를 어떻게 다룰지"만 정한다.
- 이 문서는 **법률 자문이 아니다.** 법령 조문을 읽은 것과 "내 서비스에 적용되는지"는 다르며, 적용 판단은 하지 못했다. 공개 · 실결제 전에 전문가(변호사 · 전자상거래 · 결제 분야)에게 6장의 질문 목록으로 확인받는 것을 권한다.

## 0. 먼저 알아야 할 것 — 지금은 판매 준비가 끝나지 않았다

약관 5조 · 7조 · 유료 질문 조항에 "환불 · 유효기간 · 탈퇴 때 처리는 출시 전 확정"이 남아 있는 동안은 실결제를 열면 안 된다. 코드를 점검하다 아래 세 가지를 새로 확인했다(모두 이 문서 2장에 자세히).

1. **부분 환불은 아직 장부에 반영되지 않는다.** 토스에서 일부만 취소하면 결제사 상태가 `PARTIAL_CANCELED`가 되는데, 미유는 이를 "이상 징후"로만 알리고 주문은 "결제 완료"로, 남은 질문은 그대로 둔다. 지금 반영되는 것은 **전액 취소**뿐이다.
2. **고객이 환불을 요청할 연락 채널이 사이트에 없다.** 약관 9조는 "연락처 — 출시 전 기재"로 비어 있고, 사업자 정보(`lib/config/business.ts`)에도 연락처가 없다. 탈퇴 막힘 문구는 "환불이 필요하면 운영자에게 환불을 요청한 뒤에 탈퇴해 주세요"라고 하는데(이번에 "임시 처리"임을 문구에 밝혔다) 요청할 곳이 사이트에 없다.
3. **남은 질문이 있으면 탈퇴가 막힌다**(임시 처리). 최종안이 아니다 — 3장 P4가 대안이다.

## 3. 정책안

각 항목마다 **옵션 → 추천 → 이유 → 구현에 필요한 것** 순서다. 추천은 "법이 요구해서"가 아니라 "소비자 분쟁 · 선불 성격 논란 위험을 줄이면서 혼자 운영하기에 단순한" 쪽이다.

### P1. 미사용 질문 환불

| 옵션 | 내용 | 장점 | 단점 |
| --- | --- | --- | --- |
| A | **구매 7일 안 + 쓰지 않은 질문만** 환불, 7일이 지나면 환불 없음(유효기간 안에서 쓰기만) | 환불 부담이 가장 작다 | 7일 뒤 남은 질문이 "돈만 묶인" 상태가 되어 선불 · 상품권 성격 논란이 커진다 |
| **B (추천)** | **유효기간 안이면 언제든 쓰지 않은 질문을 환불**, 수수료 없음 | 선불 성격 논란과 탈퇴 문제를 한꺼번에 줄인다(탈퇴 때도 같은 규칙) | 운영자의 수작업이 늘 수 있다(질문 1~2개당 833~1,667원 환불) |
| C | 환불 없음, 대신 탈퇴 때 소멸 안내 | 운영 단순 | F2의 단서와 부딪힐 가능성이 크다(7일 안 철회). 위험이 가장 크다 — 추천하지 않는다 |

**추천 B의 환불액**: 환불액 = 쓰지 않은 질문 수 × (2,500 ÷ 3). 원 미만은 **올림**(소비자에게 유리하게). 이미 답을 받은 질문은 환불하지 않는다. 답을 받지 못한 질문은 쓰이지 않았으므로 "쓰지 않은 질문"이다.

| 쓰지 않은 질문 | 환불액 |
| --- | --- |
| 3개 (하나도 안 씀) | 2,500원 (전액) |
| 2개 (1개 씀) | 1,667원 |
| 1개 (2개 씀) | 834원 |
| 0개 | 없음 |

- 이유: F2(쓰지 않은 부분의 철회) 때문에 **7일 안에는 최소한 이 규칙이 필요할 가능성이 높다**(해석). 7일 뒤까지 넓히는 것은 법이 요구한 것이 아니라 제안이다.
- 토스 수수료가 환불 때 돌아오는지는 확인하지 못했다(F10) — 돌아오지 않으면 환불 1건마다 수수료만큼 운영자가 부담한다.
- **구현에 필요한 것**: ① 부분 취소 반영(아래 5장 R1 — 지금은 안 된다) ② 환불 신청을 받는 곳(R2).

### P2. 유효기간

| 옵션 | 내용 |
| --- | --- |
| A | 없음(무기한). 구현은 지금 그대로. 서비스 종료 때 모든 남은 질문을 환불해야 하는 부담이 커지고 장부가 계속 남는다 |
| **B (추천)** | **마지막 구매일부터 1년.** 구매할 때마다 남은 질문의 만료일이 함께 1년 뒤로 늘어난다(묶음마다 따로 세지 않아 단순하고 소비자에게 유리). 만료 30일 전부터 MY와 채팅방 입력창에 "남은 질문 N개 · 사용 기한 ○○" 표시 |
| C | 6개월 |

- 만료 뒤 처리(제안): 질문으로는 쓸 수 없게 하되 **소멸시키지 않고 환불 신청을 받는다.** 소멸시켜도 되는지는 F7(상품권 기준에서 유효기간이 지나도 환급 의무가 있다는 요약)을 보면 **확신할 수 없으므로 전문가 확인 항목**이다.
- **구현에 필요한 것**: 지갑에 기준일 열 하나 + 쓸 수 있는 잔액 계산 → **새 DB 변경(16번)**.

### P3. 쓰지 않은 질문과 "묶음 구조"에 대한 고지

결제 화면과 약관에 다음을 구매 전에 보여 준다(F3의 표시 취지):

- "질문 3개 묶음 2,500원(부가세 포함) · 1개씩 결제할 수 없어요"
- "구매하면 적어 둔 질문에 바로 답하고 1개가 쓰여요. 남은 2개는 이어서 쓸 수 있어요"
- "쓰지 않은 질문은 환불할 수 있어요 · 사용 기한 ○○(P2)"
- 무료 질문이 먼저 있어 써 본 뒤 구매할 수 있다는 것

지금 결제 화면은 첫 두 줄까지 보이고(가격 · 낱개 없음 · 바로 답함 · 남은 질문), 환불 · 유효기간 문구는 정책 확정 전이라 "아직 확정 전"으로만 적혀 있다.

### P4. 탈퇴 — "무기한 막힘"을 최종안으로 두지 않는다

현재 임시 처리(막음)는 회원이 질문을 다 쓸 때까지 탈퇴 권리를 막는 구조라 **최종안으로 두면 안 된다.** 제안 흐름:

1. 탈퇴 화면이 "쓰지 않은 질문 N개가 있어요"와 **환불 예정액**(P1 표)을 보여 준다.
2. 회원이 **셋 중 하나**를 고른다.
   - **환불을 신청하고 탈퇴** — 신청이 접수되면 탈퇴를 진행한다. 환불은 운영자가 토스 관리자에서 실행하고(미유는 환불을 실행하지 않는다) 미유가 결제사 기록으로 맞춘다. 개인정보는 바로 지우고 주문 · 결제 · 환불 기록만 이름 없이 남긴다.
   - **환불받지 않고 포기하고 탈퇴** — "쓰지 않은 질문 N개는 사라지고 돌려받지 못한다"를 읽고 직접 확인 문구를 적으면 탈퇴를 진행하고, 포기에 동의한 사실을 기록에 남긴다. (이 선택을 둬도 되는지 자체가 전문가 확인 항목이다 — 소비자의 환불 권리를 포기시키는 구조로 읽힐 수 있다.)
   - **탈퇴하지 않음.**
3. 환불 신청이 접수됐지만 운영자가 처리하기 전에 회원이 탈퇴해도 환불은 이어진다(주문 · 결제 기록은 5년 남으므로 F6 방향과 맞다).

- **구현에 필요한 것**: 환불 신청 접수 기록(R2) + 탈퇴 함수가 "남은 질문이 있으면 막음" 대신 "환불 신청이 접수됐거나 포기 동의가 기록됐으면 허용"으로 바뀜 → **새 DB 변경(16번)**.
- **그때까지의 임시 처리**: 탈퇴를 막는 문구를 "임시"로 바꾸고, 연락 채널(0장 2번)을 정하면 그 채널로 환불을 신청한 뒤 운영자가 처리한다.

### P5. 서비스 종료 · 중단

- 종료 **30일 전**(제안) 사이트와 MY에 공지하고, 종료 전까지 환불 신청을 받는다.
- 종료 시점에 남은 질문이 있는 회원은 P1과 같은 계산으로 환불한다(운영자가 토스에서 처리).
- 토스 취소가 가능한 기간 · 수수료는 확인하지 못했다(F10). 결제 후 시간이 오래 지나 토스 취소가 안 되면 **계좌이체 등 다른 방법**이 필요할 수 있어 종료 정책 확정 전에 토스에 확인해야 한다.

### P6. 오류 · 중복 결제

- 같은 묶음을 두 번 결제한 경우: 중복분 전액 환불(지금 `runbook.md` 절차 그대로).
- 질문이 안 들어간 경우: "결제사 확인 후 질문 넣기"(15번)로 넣거나 환불.
- 결제 시작을 두 번 눌러도 결제할 수 있는 대기 주문은 하나만 남도록 코드를 고쳤고(이번 작업), 같은 승인 주소를 여러 번 열어도 질문은 한 번만 들어간다(시험함).

## 4. 약관 초안 문구 (미반영 — 결정 후 `app/terms/page.tsx` · 결제 화면에 넣는다)

> **유료 질문**: 무료 질문을 모두 쓴 뒤에는 질문 3개를 묶어서 결제하고 이어서 물을 수 있습니다(1개씩 결제하는 방법은 없습니다). 가격은 질문 3개에 2,500원(부가세 포함)입니다. 결제한 질문은 질문을 보낼 때마다 1개씩 쓰이고, 답을 받지 못한 질문은 쓰이지 않습니다.
> **사용 기한**: 결제한 질문은 마지막 결제일부터 1년 동안 사용할 수 있습니다. 기한이 지나면 질문으로는 사용할 수 없으며, 쓰지 않은 질문은 환불을 신청할 수 있습니다.
> **환불**: 쓰지 않은 질문은 사용 기한 안에 언제든 환불을 신청할 수 있습니다. 환불 금액은 쓰지 않은 질문 수 × (2,500원 ÷ 3)이며 원 미만은 올립니다. 이미 답을 받은 질문은 환불하지 않습니다. 환불은 결제수단으로 돌려드리며 신청 후 영업일 기준 ○일 안에 처리합니다.
> **회원 탈퇴**: 쓰지 않은 질문이 있는 경우 탈퇴 화면에서 환불을 신청하고 탈퇴할 수 있습니다. 주문 · 결제 · 환불 기록은 관련 법령에 따라 이름을 알 수 없는 상태로 보관합니다.
> **서비스 종료**: 서비스를 종료하는 경우 종료 30일 전에 공지하고, 쓰지 않은 질문은 위와 같은 방법으로 환불합니다.

(괄호 ○는 운영자 결정 항목. "소멸" · "환불 불가" 같은 표현은 전문가 확인 전에는 넣지 않는다.)
