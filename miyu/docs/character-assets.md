## 4. 크기 · 여백 · 대비 점검

- **여백**: 프로필 정사각형(흰 바탕)에 캐릭터가 정사각형의 약 70%를 차지하도록 같은 자리로 잘랐다. 다섯 색의 몸 크기가 같아 색이 바뀌어도 자리가 흔들리지 않는다. 390px · 1440px에서 가로 넘침 없음(홈 · 상담방 5개 · 안내 화면 · MY 미리보기를 Playwright로 확인).
- **바탕**: 보내 준 그림의 바탕이 흰색이라 `canvas`(흰색) 둥근 정사각형 프로필로 보인다. 아이보리 페이지(`#F7F5F1`) 위에서는 은은하게 떠 보이고(흰색 대 아이보리 1.09:1), 라벤더 카드(`accent-soft`) 위에서는 또렷하게 보이고(1.2:1), 흰 말풍선 옆에서는 자연스럽게 이어진다. 테두리 · 그림자를 더하지 않았다(박스를 늘리지 않는 원칙).
- **대비(몸 색 대 흰 바탕, 직접 계산)**: 라벤더 2.56 · 핑크 2.12 · 연두 2.10 · 민트 1.80 · 옐로 1.73. 민트와 옐로는 연해서 흰 바탕에서 가장 약하다 — 장식이라 보조기기에는 숨기고 글자(방 이름)가 의미를 말하며, 눈(어두운 색)과 음영이 윤곽을 잡아 준다. 더 또렷하게 하려면 프로필에 연한 테두리를 더하는 방법이 있지만 UI 변경이라 하지 않았다.
- **해상도 한계(운영자 확인 필요)**: 받은 그림은 128px 썸네일이라 잘라낸 100px이 원본이다. 40~48px 자리는 2배 화면에서도 선명하지만 56~64px 자리(잠긴 방 · 안내창 · 초대 화면)는 2배 화면에서 약간 부드럽게 보일 수 있다. **원본 해상도(512px 이상) 파일을 받으면 같은 이름으로 덮어쓰기만 하면 된다.**

## 5. 하지 않은 것 · 알아 둘 것

- 표정(생각 중 · 걱정 · 손 흔들기 · 안경 · 아하)은 이 그림 세트에 없어서 **그림이 색마다 하나뿐**이다. 기존 코드의 `mood`는 남아 있지만 그림을 바꾸지 않는다. 표정을 더하고 싶으면 운영자가 그림을 주고 `miyu-moods.ts`에서 (색, 표정)으로 넓힌다.
- 라벤더의 웃는 눈과 핑크의 윙크는 보내 준 그림 그대로다(고민 상담 · 연애 영역에서만 쓰므로 "그 외 영역은 기본형 느낌 유지"에 어긋나지 않는다).
- 이 변경은 개발 서버 화면으로만 확인했다. 실제 휴대폰 · 실제 로그인 상태의 화면은 보지 못했다.
