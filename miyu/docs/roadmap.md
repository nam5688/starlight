# ME:U(미유) 진행 단계

개인 통합 리포트 하나부터 완성한다. 한 번에 한 단계씩 진행하고, 단계가 끝나면 사용자가 화면을 확인한 뒤 다음으로 넘어간다.

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1 | 화면과 흐름 (샘플 데이터) | **구현 완료 · 디자인 확인 대기** |
| 2 | 검사 도구·사주 엔진 검토와 연결, 카카오 로그인·결과 저장 | 대기 |
| 3 | 테스트 결제·구매 권한·리포트 생성·MY·관리자 | 대기 |
| 4 | 텔레그램 알림·쿠폰·출시 검수 | 대기 |

---

## 1단계 — 화면과 흐름

### 구현 계획

1. 실행 환경 확인 (Node.js 22, Next.js 16.4, 기존 미유 HTML·V6 파일 없음).
2. `miyu/` 폴더에 Next.js + TypeScript 프로젝트 구성. 추가 패키지는 글꼴(Pretendard)만.
3. 검사 모듈 · 채점 · 샘플 데이터 · 화면 부품 · 외부 연결 상태를 파일로 분리.
4. 메인 → 기본 정보 → 검사(MBTI 성향 · 기질 · 관계) → 서버 채점 → 무료 요약.
5. 로그인·구매 위치는 "연결 전"으로 표시하고 동작하지 않게 둔다 (가짜 성공 없음).
6. 리포트 예시(전체 7단계 구성)와 MY(연결 전 상태) 화면.
7. 타입 검사 · 린트 · 단위 테스트 · 빌드 · 실제 브라우저 검사(390px / 1440px).

### 완료 항목

- [x] 메인: 핵심 소개 → 실제 리포트 예시 → 제공 항목 → 이용 방법·가격(9,900원 가안) → 자주 묻는 질문
- [x] 기본 정보: 닉네임, 생년월일(양/음력·윤달), 출생시간/모름, 알고 있는 MBTI(선택), 지역(선택, 분석 미사용)
- [x] 검사: 모듈 3개(개발용 예시 문항 22개), 진행 표시, 이전 단계·답변 수정, 휴대폰/브라우저 뒤로 가기 연동, 미응답 안내
- [x] 서버 채점(`app/analyze/actions.ts`) → 무료 요약. 응답 저장·로그 없음
- [x] 무료 요약: 대표 경향 · 한 줄 요약 · 핵심 요약 · 항목별 점수 · 분석에 사용한 정보(사주 "연결 전") · 잠긴 상세 리포트 안내
- [x] 상세 리포트 내용은 무료 요약 화면에 내려가지 않음 (자동 검사로 확인)
- [x] 리포트 예시: 7단계 구성, 네 가지 상세 분석 펼치기, 통합 해석(공통점 / 다른 관점)
- [x] MY: 로그인 연결 전 상태
- [x] 문서: `CLAUDE.md`, `product-spec.md`, `roadmap.md`, `README.md`, `.env.example`

## 2단계 — 검사 도구·사주 엔진, 카카오 로그인·결과 저장

사용자가 준비할 것 (계정 생성은 직접, 키는 대화에 붙여넣지 않고 `.env.local`·Vercel 설정에 입력):

- Supabase 프로젝트
- 카카오 개발자 앱 (카카오 로그인 활성화, 동의 항목 설정)
- 사용할 검사 척도와 이용 조건 결정

작업:

- [ ] 검사 척도 후보 검토 → 이용 조건 확인 → 운영 문항 `licensed`로 교체 (개발용 예시와 분리 유지)
- [ ] 사주 엔진 후보 검토(정확도·라이선스) → `lib/saju/engine.ts`에 연결 → 기획서 6장 검수 항목 테스트
- [ ] Supabase 연결, 카카오 로그인 (이메일 미제공 계정 포함)
- [ ] 표 구성과 RLS: profiles, birth_profiles, regions, assessments, assessment_results
- [ ] 로그인 회원의 검사 결과 저장·재열람
- [ ] 다른 회원 결과 접근 차단 자동 테스트

완료 기준: 카카오로 로그인 → 검사 → 저장 → 다시 열기가 되고, 다른 계정으로는 열리지 않는다.

## 3단계 — 테스트 결제·구매 권한·리포트 생성·MY·관리자

사용자가 준비할 것: 토스페이먼츠 테스트 키, AI API 키(리포트 생성용)

- [ ] 주문 생성(서버 금액 결정) → 토스 테스트 결제 → 서버 승인 확인 → 구매 권한
- [ ] 웹훅 처리(재확인·멱등), 중복 클릭·연결 끊김 처리
- [ ] 리포트 생성 작업: 구조화된 결과 → AI 해석 → 형식 검증 → 저장(버전 고정), 실패 시 재시도
- [ ] MY: 구매한 리포트 목록과 같은 버전 다시보기, "결제 확인 중"·"생성 중" 상태 표시
- [ ] 관리자: 주문·생성 실패·재처리·환불 요청 상태 (실제 환불은 운영자 승인 후)
- [ ] 실결제는 켜지 않음

## 4단계 — 텔레그램 알림·쿠폰·출시 검수

- [ ] 텔레그램 운영 알림 (개인정보 없음, 실패해도 결제·리포트에 영향 없음)
- [ ] 첫 가입 50% 쿠폰 (계정당 첫 구매 1회, 중복 방지, 유효기간 — 서버 관리)
- [ ] 출시 검수: 개인정보 처리방침·이용약관·환불 정책, 접근 권한 점검, 실결제 전환(사용자 승인)
