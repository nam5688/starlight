## 3. 미유 계산 기준 (`lib/saju/policy.ts`)

| 항목 | 기준 | 비고 |
| --- | --- | --- |
| 양력 | 입력한 한국 시계 시각 그대로 | |
| 음력 | KASI 기준 **한국 음력**을 양력으로 바꿔 계산 | 한 · 중 음력이 다른 날짜가 있어 중국 기준을 쓰지 않음 |
| 윤달 | 그 해에 해당 윤달이 있는지 확인. 없으면 첫 입력 단계에서 "○○년에는 음력 윤○월이 없습니다" | 음력 달 길이(29/30일)도 확인 |
| 연주 | 설날이 아니라 **입춘 절입 순간** 기준 | |
| 월주 | 12절(節) 절입 순간 기준 | |
| 출생시간 모름 | **시주를 만들지 않는다** (임의 시간 금지). 연 · 월 · 일 세 기둥, 일주는 날짜 기준 | 태어난 날에 절기가 바뀌면 연주 · 월주 후보를 함께 안내 |
| 과거 표준시 · 서머타임 | 1954~1961 UTC+8:30, 1948~51 · 1955~60 · 1987~88 서머타임 반영 | IANA 시간대 자료(1970년 이전 자료는 오차 가능성 있음) |
| 지방시 보정 | 동경 127.5°(한반도 평균) 기준 → 한국 표준시보다 30분 늦게 | 출생지를 받지 않아 고정값. 균시차는 적용하지 않음 |
| 자시 | 보정 후 밤 11시부터 **다음 날 일주** (자시 일주 변경) | 다른 관법(야자시)과 일주가 달라지면 결과에 안내 |
| 경계 근처 | 시주 · 절기 경계와 10분 이내면 "몇 분 차이로 ○주가 바뀔 수 있음" 안내 | |
| 지원 범위 | 출생 연도 1900년~현재 | 엔진 자체는 1800~2300 |
| 해외 출생 | 1차 범위 밖 (한국 시간으로 계산) | 이후 출생지 · 시간대 입력 검토 |

바꿀 수 있는 기본값(운영자 결정): 자시 관법(`jasi` / `splitJasi` / `midnight`), 지방시 보정(경도 · 끄기), 균시차.

## 4. 대운 · 세운

- **대운**: 성별이 있을 때만 계산한다. 양년생 남성 · 음년생 여성은 순행, 그 외 역행. 출생부터 다음(순행) 또는 이전(역행) 절까지 날수 ÷ 3 = 대운수 (3일 = 1년, 1일 = 4개월). 미유는 대운 시작을 **양력 연-월**로 표시한다(대운수 반올림 · 나이 셈법 차이로 생기는 1년 혼동을 피함).
- 출생시간을 모르면 대운 시작 시점이 몇 개월 달라질 수 있다.
- **세운 · 월운 · 일진**: 날짜만으로 정해지는 값이라 같은 기간을 다시 열어도 바뀌지 않는다 (한국 시간 기준, 월은 절기 기준).

## 5. 계산하지 않는 것 (해석 영역)

- 지장간 · 격국 판정 · 신강/신약 점수 · 신살 · 12운성: 학파마다 기준이 달라 엔진 결과로 단정하지 않는다. 해석 규칙에서 "단서"로만 다루고, 규칙 버전과 함께 기록한다.
- 만세력이 정확하다는 것과 미래를 맞힌다는 것은 다르다. 리포트에 이 구분을 적는다.
