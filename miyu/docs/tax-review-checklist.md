# 출시 전 세무사 · 법률 확인 체크리스트 (사업자 · 세무 · 포인트 · 쿠폰 · 추천 보상)

> **이 문서는 세무 · 법률 자문이 아니다.** 운영자가 세무사(필요하면 변호사)에게 물을 항목을 정리한 목록이며, 아래 "알려진 것"은 개발 중 검색으로 확인한 **방향**일 뿐 조문 · 유권해석 원문을 확인한 것이 아니다. 사업자등록 신청 · 세무 신고는 하지 않았고 운영자 승인 없이 하지 않는다.
> 기준(운영자 2026-10-17): 미유를 기존 슬링샵(2022년 1월 개업, 전자상거래 소매업)과 **별도의 개인사업자**로 등록하는 방향 · 2026년 신규 창업 · 인천 송도 또는 영종도 · AI 사주 · 궁합 디지털 콘텐츠 · 상담 서비스 · 청년창업 세액감면 75% 적용 **가능성**.
> **세무 확인은 개발이 끝난 뒤가 아니라 지금부터 병행한다** — 업종이나 사업자 구조가 바뀌면 PG 계약 · 영수증 · 사업자정보 · 이용약관이 함께 바뀌기 때문이다.

---

## 먼저 확인할 세 가지 (운영자 지정)

1. **신규 창업 인정 여부** — 기존 슬링샵(2022년 창업 통신판매업)이 있는 상태에서 미유를 별도 사업장에서 디지털 콘텐츠 · 정보서비스업으로 시작하는 것이 **새로운 창업**으로 인정되는지.
2. **감면율과 기간** — 실제 송도 · 영종 사업장 주소가 과밀억제권역 밖인지, 청년 요건을 충족하는지, **75% 감면 대상**인지, 감면 기간과 한도는 어떻게 되는지.
3. **부가세와 소득세** — 미유 업종에 맞는 과세 유형은 무엇인지, 기존 슬링샵 소득과 합산했을 때 감면세액을 어떻게 계산하는지.

> 목표: **미유는 75% 감면을 받을 때만 수익이 나는 사업이 아니라, 감면이 전혀 없어도 수익이 나는 구조**여야 한다. 감면은 추가 이익으로 본다(`docs/profit-model.md` 7장: 기본 가정에서는 0%도 이익).

## A. 신규 창업 인정 · 감면 요건 (조세특례제한법 제6조)

| # | 확인 | 알려진 것 · 개발 쪽 가정 | 확인 못 한 것 |
| --- | --- | --- | --- |
| A1 | 슬링샵과 별도의 **신규 창업으로 인정**되는가 | 운영자가 전달: 국세청 유권해석 **서면-2024-소득-0017**이 기존 사업과 연관성이 없는 별도 업종의 신규 사업을 창업으로 인정할 가능성을 열어 둔다. 검색한 요약 자료는 "기존 사업에 업종을 추가하는 것 · 기존 사업체 인수 · 폐업 후 동일 업종 재창업"은 감면 불가라고 설명 | **유권해석 원문을 확인하지 못했다.** 한국표준산업분류상 슬링샵(소매)과 미유가 서로 다른 세분류인지, 같은 대표자의 별도 사업장 · 별도 사업자등록이 "업종 추가"로 읽히지 않는지 |
| A2 | **업종 코드** — AI 사주 · 궁합 디지털 서비스를 어느 업종으로 등록하는가, 그 업종이 **감면 대상 업종**(조특법 시행령 제5조)인가 | 업종은 **실제 사업 내용에 맞게** 정해야 하며 감면을 받으려고 코드를 고르는 것이 아니다. 검색 요약: 감면 대상은 시행령이 정한 업종뿐 | **점술 · 사주 · 운세 서비스가 감면 대상 업종인지(소비성 서비스 등 제외 가능성) 확인하지 못했다.** 정보서비스업 · 온라인 콘텐츠 · 상담 서비스 중 어디에 해당하는지는 세무사가 사업 내용을 보고 정한다. **이 항목이 75% 계산의 전제이므로 가장 먼저 정한다** |
| A3 | **청년 요건** | 검색 요약: 창업 당시 만 15세 이상 34세 이하(군 복무 기간은 최대 6년까지 차감) | 운영자의 해당 여부 — 개발 쪽은 모른다 |
| A4 | **사업장 주소** — 송도 · 영종 사업장이 수도권 **과밀억제권역 밖**인가 | 검색 요약: 인천은 원칙적으로 과밀억제권역이고 강화군 · 옹진군 · 서구 일부 동 · **인천경제자유구역(송도 · 영종 포함, 해제 지역 포함)** · 남동국가산업단지는 제외. 2026년 이후 수도권(과밀억제권역 · 인구감소지역 제외)은 75% | **현행 수도권정비계획법 시행령 별표 1 원문 대조 필요.** 구 · 동 · 지번에 따라 달라질 수 있어 **사업장 주소가 확정된 뒤** 지번 단위로 확인. 이전 · 확장 시 감면율 변동(사업장 이전 규정)도 확인 |
| A5 | **실제 사업장 요건** — 임대차 계약 · 비상주 · 공유오피스 · 자택 | 사업장이 감면 판단의 주소다 | 실제 사업 활동 장소로 인정받는 기준 · 임대료(손익 영향: 월 30만원이면 손익분기가 월 24명 → 93명) |
| A6 | **감면율 · 기간** | 검색 요약: 2026년 1월 1일 이후 창업 청년창업중소기업은 수도권(과밀억제권역 · 인구감소지역 제외) **75%**, 수도권 외 · 인구감소지역 100%, 감면기간은 첫 소득 발생 과세연도부터 5년, 창업 기한 2027-12-31 | **조문 원문 확인 필요.** 75%가 **확정이 아니다** — 코드는 0 · 50 · 75% 세 시나리오를 입력으로 받는다 |
| A7 | **감면 한도 · 최저한세 · 농어촌특별세 · 사후관리(추징)** | 계산하지 않았다 | 연 감면 한도, 최저한세 적용 여부, 농특세 부과 여부, 요건 위반 시 추징 |
| A8 | **다른 감면 · 공제와의 중복 배제** | 계산하지 않았다 | 슬링샵에 적용 중인 감면이 있는지 |
| A9 | **감면세액 계산식** — 감면 대상 소득(미유)과 비대상 소득(슬링샵)을 합산 소득세에서 어떻게 안분하는가 | 코드는 산출세액 × (미유 소득 ÷ 종합소득금액) × 감면율로 가정 | 사업장별 소득 구분 방법(장부 구분), 결손금 통산 시 안분 |

## B. 과세 유형 · 부가세

| # | 확인 | 알려진 것 · 개발 쪽 가정 |
| --- | --- | --- |
| B1 | **일반과세 vs 간이과세** — 미유 업종의 과세 유형, 간이과세 **배제 업종** 여부, 일반과세 선택(간이 포기) | 검색 요약: 직전 연도 공급대가 1억 400만원 미만이면 간이과세 대상, 4,800만원 미만이면 납부 면제, 광업 · 제조업 · 도매업 · 전문직 등은 배제, 연중 개업은 12개월로 환산해 판정. **2026년 적용 여부와 미유 업종의 배제 여부는 확인하지 못했다** |
| B2 | **간이과세 부가가치율** | 업종별 15~40% 범위로만 알려져 있다. 미유 업종 확정 전이라 코드 기본값은 보수적으로 40% — **정확한 율은 업종이 정해진 뒤** |
| B3 | 간이과세자의 **세금계산서 · 영수증** 발급과 소비자 판매 증빙 | 소비자 판매는 신용카드 매출전표 · 현금영수증으로 증빙되는 것으로 알고 있으나 확인 필요 |
| B4 | **해외 AI API 비용(Anthropic 등)**의 부가세 · 필요경비 처리 | 코드 가정: 매입세액 공제 없음(0), 비용은 증빙 금액 그대로 필요경비. **해외 사업자의 국내 부가세 징수 · 간편사업자등록 여부, 대리납부 의무 여부, 인보이스의 증빙 인정 범위는 확인하지 못했다** |
| B5 | **PG 수수료**(토스페이먼츠)의 매입세액 공제와 세금계산서 수취 | 코드 가정: 수수료의 부가세는 일반과세에서 공제 |
| B6 | **환불 · 취소 · 부분 환불**(질문 묶음)의 매출 조정과 부가세 정정 | |
| B7 | **질문 3개 묶음(미사용 질문이 최대 2개 남는 구조)**의 매출 인식 시점 — 결제 시점 vs 사용 시점, 선수금 | 코드 · 지표는 결제 시점(실결제만)으로 센다. 회계 · 부가세 인식과 다를 수 있다 |

| C4 | **리뷰 보상 질문권**의 대가성 — 광고선전비 처리, 후기에 대가 표시 의무 | 설계에 "혜택 제공 사실 표시"를 넣었다. 표시 기준은 법률 확인 |
